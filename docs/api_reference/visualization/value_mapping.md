# Value Mapping

Value mappings turn data values into visual properties, such as colors, line widths or opacities. Discrete mappings map single values; continuous mappings map number ranges; a rule-based mapping calls a function. Import `is_missing`, the discrete and the continuous mapping classes from `mesqual.visualizations.value_mapping_system`. These classes stay in their modules: `BaseMapping` in `mesqual.visualizations.value_mapping_system.base`, `SegmentedContinuousInputMappingBase` in `mesqual.visualizations.value_mapping_system.continuous`, `RuleBasedMapping` in `mesqual.visualizations.value_mapping_system.rule`.
